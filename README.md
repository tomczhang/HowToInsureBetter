## 一、配置总纲：先立 4 条铁律

在挑任何一款具体产品前，先守住这 4 条方向性底线：

| 总纲铁律 | ✅ 正确做法（高性价比） | ❌ 常见大坑 | 底层逻辑 |
| :--- | :--- | :--- | :--- |
| **1. 只买「单一职责」，不买组合险** | **拆开单买、各管一摊**（医疗、意外、定寿、重疾各自选全市场头部产品自由拼装） | 买“重疾 + 医疗 + 意外 + 寿险 + 分红”一张保单全包圆的**组合捆绑险** | 组合险常暗藏**价格贵、保额共享（主险赔完附险跟着失效）、无法跨公司挑最优、后期拆不开单换**等硬伤 |
| **2. 只买「纯消费型」，返还分红不是高优** | **普通人优先买纯消费型**（把保费砸在极端风险的高杠杆上）；保障配齐后再单独考虑投资 | 迷信“有病治病、没病返本”的**返还型 / 分红保障险** | 返还/分红保障险本质是让你每年多交保费换低息返还，**保障额度被腰斩、理财收益又跑不赢正经资产，两头不讨好**；牢记：**保障归保障，投资归投资** |
| **3. 预算红线（现金流约束）** | 全家纯保障型总保费控制在**家庭税后年收入的 5% 以内**（手头紧压到 1%～2% 先配齐医疗+意外也完全够用） | 轻信保险行业“双十原则”拿年收入 10% 买保险，背上二三十年刚性缴费负荷 | 重疾、定寿一交就是二三十年，本质是长期负债；**一旦失业降薪，负荷太高直接面临断供退保亏本金**。硬底线：**哪怕突然没了工作，靠应急钱也能轻松撑过一两年续费** |
| **4. 先配中间，再配两边** | 优先配齐**家庭支柱**，再顾孩子和父母；预算紧时优先保足保额 | 先给孩子买上万块“全家桶”，大人却在裸奔；或给 50+ 父母硬买保费倒挂的重疾险 | **保险只讲究保护家庭现金流，不讲究尊老爱幼**——家庭支柱的赚钱能力才是全家最大的“保单” |

## 三、按家庭财务阶段“对号入座”

不用一步到位，按手里现金流状况分阶段往上叠就行：

| 家庭阶段 | 核心痛点 | 推荐优先组合 |
| :--- | :--- | :--- |
| **阶段 1：存款刚起步 / 手头紧** | 现金流脆弱，经不起任何硬保费拖累 | **国家医保** + **3～6 个月应急备用金** + 几百块**百万医疗险 & 综合意外险**（先花小钱防灭顶之灾） |
| **阶段 2：有娃 + 房贷主力中产** | 最怕“工资归零 + 大病花钱”双向夹击 | 在阶段 1 基础上，给家庭支柱配齐**定期寿险**，有余力再依次补齐全家**重疾险**，父母同步配齐**医保 + 老年意外 + 百万医疗（过不了健告换惠民保等政府全民大病险）** |
| **阶段 3：保障已齐 / 闲钱充裕** | 资产保值、低风险压舱石或跨境分散 | 结合自身投资能力与外汇诉求，再理性评估**分红储蓄险**或**香港保险**（绝不拿应急钱或保障钱去买） |

## 四、每份分册怎么配合 AI 高效使用？

每份险种文档结构完全统一（**核心定位 → 配置优先级 → 适合谁 → 大概成本 → 核心考量优先级 → 主要误区 → 投保前 AI 核对 Prompt**），标准实操只需 3 步：

1. **榜单初筛**：在小红书 / 深蓝保等保险销售平台中找热销榜单——**互联网社会，热销的不一定好，不热销的一定不好**，再按对应分册第 5 节的「P0 → P1 考量权重」把排名前几的圈出来。
2. **用第 7 节 Prompt 审合同**：把对应的合同条款 PDF + 健康告知全文 + 真实体检报告一起喂给 AI，**强制 AI 对每条结论标出合同原话和页码，防止 AI 胡编**（也可以直接把整个 GitHub 仓库扔给你的 AI）。
3. **把经纪人当工具**：经纪人和平台只是负责提供信息的工具，不完全相信他们，决策只靠自己——**权责统一，只有自己才能为自己负责。**
