## 1. 核心定位

> **全市场最被低估的“带病投保神器”——由地方医保局指导推出，不限年龄、不限职业、免健康告知，核心杀手锏是「能保既往症」。**
>
> 因为这类产品几乎没佣金，还会分流商业险客户，保险经纪通常绝口不提；但它恰恰是高龄父母和已经查出结节、三高、大病病史人群最宝贵的兜底防线。

## 2. 配置优先级

`🔴 P0.5 高（长辈与非标体刚需 / 健康年轻人低成本备胎）` —— 只要在支持**刷医保个账余额支付**的城市（如杭州西湖益联保等），连现金都不用掏，全家顺手配齐几乎没有心理负担；对买不了百万医疗险的父母，它就是无可替代的第一防线。

## 3. 适合谁

| 人群 | 推荐度 | 配置策略与关注重点 |
| :--- | :--- | :--- |
| **少儿** | 🟡 按需补充 | 健康孩子优先买百万医疗险；若孩子有先天/既往病史被商业险除外或拒保，立刻配惠民保兜底 |
| **家庭支柱** | 🟡 视体检与个账 | 体检有结节/三高被百万医疗**除外**的部位，靠惠民保精准补洞；医保个账充裕且可刷卡的城市直接闭眼配 |
| **退休长辈** | 🟢 强烈建议 | 超过 60 岁、有三高/心脑血管/肿瘤病史买不了百万医疗的父母，**惠民保等政府保既往症的全民大病险**就是最实在的兜底（能保既往症的保险少之又少） |

## 4. 大概成本

*基准参考：全国主流城市政府指导版惠民保（如北京普惠健康保、上海沪惠保、杭州西湖益联保、深圳惠民保等），普遍实行均一费率或按年龄粗分两档。*

| 城市/年龄档 | 基准保额 | 年缴参考保费 | 缴费特点 |
| :--- | :--- | :--- | :--- |
| **全年龄统一价城市** | 100万～300万 | ¥89 ～ ¥195 / 年 | 不论 3 岁还是 80 岁同价，老年人杠杆极高 |
| **分年龄段定价城市（少儿/青年）** | 100万～300万 | ¥59 ～ ¥120 / 年 | 价格极低，常支持职工医保个账给全家一键代缴 |
| **分年龄段定价城市（中老年）** | 100万～300万 | ¥150 ～ ¥260 / 年 | 对比商业医疗险动辄 ¥3,000+ 的高龄保费，成本不到十分之一 |

## 5. 核心考量因素优先级

| 权重 | 考量因素 | 筛选硬标准 | 为什么排这里 |
| :---: | :--- | :--- | :--- |
| **P0** | **认准“政府指导”官方正牌** | 明确由当地**医保局/金融监管局**指导推出 | 市面上有不少民营机构仿冒的“假惠民保”，实则是高门槛商业险，专坑老人 |
| **P0** | **既往症赔付规则** | 看清既往症是否**可保可赔**、具体赔付比例多少 | 惠民保的核心价值就是保既往症；部分城市既往症全免责，这类价值就大打折扣 |
| **P1** | **保障责任范围** | 必须覆盖**医保目录外自费药 + 院外特药清单** | 只保医保目录内自付的惠民保作用很有限，大病烧钱的是目录外和院外靶向药 |
| **P1** | **免赔额与报销比例** | 关注各项责任是否**分开算免赔额**、比例是否 ≥ 60% | 很多惠民保把目录内、目录外、特药拆成 3 个独立 1.5万～2万免赔额，实际理赔门槛偏高 |
| **P2** | **医保个账支付与一站式结算** | 优先选支持刷个账余额 + 出院医保同步直赔 | 既不占现金流，又省去大病后自己攒一堆发票跑报销的折腾 |
| **P2** | **集中参保窗口期** | 牢记当地每年固定开放的 1–2 个月投保期 | 多数惠民保一年只开放一次窗口，错过要再等整整一年 |

## 6. 主要误区

1. **❌ “买了惠民保，就不用再买商业百万医疗险了”**
   → **✅ 真实情况**：身体健康、年龄合适的人**绝不能用惠民保平替百万医疗**。惠民保通常免赔额更高（1.5万～2万起，且多项分开算）、报销比例更低（多为 50%～80%，既往症更低），而且**不保证续保**，次年可能调条款。能买百万医疗一定要先买百万医疗。
2. **❌ “惠民保免健告，所以只要是之前的老毛病都能 100% 报销”**
   → **✅ 真实情况**：各地细则差异巨大！有些城市既往症可赔但比例打折（如 30%～50%），有些城市对约定的 5～10 类严重既往症直接免责不赔，买前必须看清当地细则。
3. **❌ “看到朋友圈刷屏的‘某地惠民保’就顺手下单”**
   → **✅ 真实情况**：认准当地医保局官方公众号或支付宝/微信官方入口。很多打着“惠民”旗号的商业一年期医疗险，不仅不保既往症，第二年还可能停售割韭菜。

## 7. 投保前 AI 核对重点

惠民保一城一策，且每年条款都会微调。投保前把当地当年官方版**《产品说明书 / 投保须知 / 既往症约定 / 特药清单》**发给 AI，直接复制下面这段 Prompt：

```text
你是一位严谨的保险条款分析顾问。我上传了【填写城市与产品名，例如：2026版西湖益联保】的官方投保须知与条款说明。请逐项拆解，并遵守证据铁律：**每条结论必须附上原文条款位置与原话摘录，文件里没写明的直接标注“原文未提及”，严禁拿其他城市惠民保规则脑补。**

请按以下 4 项输出核查结果：
1. 【既往症界定与赔付】：原文如何定义“特定既往症”？对既往症是“照常赔付”、“降低比例赔付（具体几成）”还是“直接免责”？
2. 【免赔额陷阱排查】：医保目录内自付、医保目录外自费、院外特药这几项责任，免赔额是“合并共享”还是“各自独立计算”？各项具体免赔额与报销比例是多少？
3. 【与百万医疗的互补关系】：如果我已经买了百万医疗险（但某部位被除外），这款惠民保能否覆盖我的除外部位？若未除外，两者理赔时如何衔接（能否互相抵扣免赔额）？
4. 【支付与续保规则】：是否支持刷职工医保个账为家人投保？是否有连续参保优待（如降免赔额或提高比例）？
```
