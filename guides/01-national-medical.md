## 1. 核心定位

> **国家给每个人的最划算、最底层医疗兜底，唯一真正做到“不问健康、带病可保、终身续保”的医疗保障。**
>
> 它不仅承担日常门诊和住院的基础报销，更是后续购买**地方惠民保**和**商业百万医疗险**的“入场券”（无医保状态下，商业医疗险保费会暴涨且报销比例大幅缩水）。

## 2. 配置优先级

`🔴 P0 极高（所有险种第一顺位）` —— 全市场性价比最高的保险，没有任何商业险能替代它的“带病可保”与“终身保证续保”。不管有没有预算买商业险，国家医保必须先交上、绝不断缴。

## 3. 适合谁

| 人群 | 推荐度 | 配置策略与关注重点 |
| :--- | :--- | :--- |
| **少儿** | 🟢 绝对必配 | 出生后尽早办理**少儿城乡居民医保**（很多城市出生 90 天内参保可追溯报销新生儿住院费） |
| **家庭支柱** | 🟢 绝对必配 | 在职优先走**职工医保**；离职/自由职业期千万别断缴，立刻转**灵活就业医保**或居民医保衔接 |
| **退休长辈** | 🟢 绝对必配 | 职工医保缴满当地规定年限（通常男 25–30 年 / 女 20–25 年）可终身免缴享受待遇；未缴满则务必按年续交居民医保 |

## 4. 大概成本

*基准参考：全国主流省市 2025–2026 年度标准，具体金额随各地社平工资与医保局政策微调。*

| 参保类型 | 适用人群 | 年缴参考成本 | 缴费与待遇特点 |
| :--- | :--- | :--- | :--- |
| **城乡居民医保** | 少儿、老人、无业居民 | ¥380 ～ ¥700 / 年（个人） | 国家财政同步补贴大头；一年一交，错过集中缴费期会有**等待期** |
| **职工医保（在职）** | 上班族 | 个人扣工资基数 2%（公司另缴 6%～10%） | 报销比例显著高于居民医保，且有**医保个人账户**（可家庭共济） |
| **灵活就业医保** | 自由职业 / 离职空窗期 | ¥4,000 ～ ¥7,000 / 年（各地差异大） | 个人全额承担，但享受职工医保高报销比例并累计退休缴费年限 |

## 5. 核心考量因素优先级

| 权重 | 考量因素 | 实操硬标准 | 为什么排这里 |
| :---: | :--- | :--- | :--- |
| **P0** | **参保连续性（绝不断缴）** | 离职/跨城换工作 3 个月内完成接续 | 断缴期间生病住院医保直接停报，重新参保还可能触发 3 个月待遇等待期 |
| **P0** | **医保类型选择** | 能交**职工医保**优先职工，其次居民医保 | 职工医保住院报销比例（常 80%–90%+）与封顶线明显高于居民医保（常 50%–75%） |
| **P1** | **家庭共济绑定** | 在“国家医保服务平台/当地小程序”绑定家人 | 职工医保个账余额可直接给爸妈、配偶、娃付门诊自付、买药，甚至代缴居民医保/惠民保 |
| **P1** | **异地就医备案** | 跨省/异地住院前，手机 2 分钟完成线上备案 | 不备案直接异地住院，报销比例往往直降 10%～20% 甚至无法直接结算 |
| **P2** | **退休累计缴费年限** | 提前核对当地职工医保退休年限与补缴政策 | 临近退休才发现差几年没缴够，一次性补缴可能要掏几万块 |
| **P2** | **慢特病门诊认定** | 父母若有高血压、糖尿病、肿瘤放化疗，及时申请认定 | 认定后门诊开药享受高比例统筹报销，每年能省下数千元长期药费 |

## 6. 主要误区

1. **❌ “我还年轻身体好，离职空窗期先断几个月医保省点钱”**
   → **✅ 真实情况**：断缴当月或次月就会冻结医保待遇，万一空窗期突发急性病或意外住院，一分钱报不了；且如今多地对断缴再参保设有数月等待期，极其划不来。
2. **❌ “交了医保就万事大吉，生大病国家全管”**
   → **✅ 真实情况**：医保的原则是“广覆盖、保基本”，存在**起付线、封顶线、报销比例**和**三大目录限制**（进口靶向药、院外特药、高端耗材大多全自费），大病高额缺口必须靠商业医疗险补齐。
3. **❌ “医保个人账户的钱只能自己用，放着也是闲着”**
   → **✅ 真实情况**：全国已普遍推行**职工医保家庭共济**，把配偶、父母、子女绑定进去后，不仅能共付看病买药自费部分，在杭州等城市还能直接刷个账给全家买地方惠民保。

## 7. 实操前 AI 核对重点

国家医保政策**强地域差异**（每个城市的报销比例、起付线、个账共济范围、退休年限都不同）。把你所在城市的官方医保局文件发给 AI，或让带联网搜索的 AI 核对当地最新口径，直接复制下面这段 Prompt：

```text
你是一位熟悉中国各地医保政策的实操顾问。我目前参保地为【填写你的城市，例如：杭州】，参保类型为【职工医保 / 城乡居民医保 / 灵活就业医保】，家里还有【填写成员，例如：退休父母、2岁孩子】。

请联网检索并严格遵守证据规则：**每条政策结论必须附上官方出处（医保局公告/文件名称、年份、官方链接或原文条款摘录），不确定的地方直接标明“需致电当地 12393 医保热线确认”，严禁拿外地政策套用或凭记忆编造。**

请帮我输出一份 4 项实操核查清单：
1. 【本地报销底线】：列明当前城市三甲医院住院的起付线、目录内报销比例、统筹封顶线及大病保险二次报销规则。
2. 【断缴与等待期】：明确当前城市若离职断缴或错过居民医保集中缴费期，重新参保的待遇等待期是几个月。
3. 【家庭共济权限】：确认职工医保个账能否给父母/配偶/子女代缴居民医保及本地惠民保，并给出官方线上办理入口名称。
4. 【异地就医与慢特病】：确认去北上广等外地三甲就医的备案流程与报销比例折损情况，以及常见慢特病门诊认定条件。
```
