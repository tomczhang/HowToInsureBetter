## 1. 核心定位

> **说穿了，分红储蓄险（含增额终身寿、分红年金险）本质上不是“保险”，而是一种带长期锁定期的「固收+ 低风险金融理财工具」。**
>
> 它不具备用小钱撬动大钱的保障杠杆，而是帮你把一笔 **5～10 年以上绝对用不到的闲钱** 锁定在一个低波动账户里，赚取“写进合同的保底复利 + 随保险公司投资表现浮动的红利”。政府现在也开始收资本利得税了，所以**它其实是资产，不是保险**。

## 2. 配置优先级

`⚪ P4 低（家庭保障配齐后的资产配置选项）` —— 只有在**医保 + 应急金 + 医疗险 + 意外险（及必要的定寿/重疾）全部配齐**、且你**对股票/宽基指数不感兴趣**，或者单纯为了**做家庭资产的低风险压舱石/分散配置**时，才值得腾出时间研究。

## 3. 适合谁

| 人群 | 推荐度 | 配置策略与关注重点 |
| :--- | :--- | :--- |
| **少儿** | 🟡 视家庭闲钱 | 适合作为**压岁钱 / 教育金长期池**（利用孩子超长复利周期），但前提是父母自身保障已齐、且这笔钱十几年内绝不急用 |
| **家庭支柱** | 🟡 资产分散可选 | 适合风险偏好极低、存不下钱（需要强制储蓄），或权益资产仓位已很高、需要配一块**长期锁息固收底仓**的中产家庭 |
| **退休长辈** | 🟠 慎买锁定期产品 | 老人最看重**流动性与随时取现**；若拿养老救命钱买前期退保亏本的储蓄险极易被动。仅限大额闲钱做养老补充或定向传承时考虑 |

## 4. 大概成本（起投门槛与资金占用）

*与消费型保障险不同，储蓄险投入的是你的**本金**（不是花掉的保费），核心“成本”是长达 5～10 年的**流动性锁定**与**早期退保损失**。*

| 常见产品形态 | 常见起投门槛 | 缴费期选择 | 资金回本（现金价值 ≥ 累计保费）参考周期 |
| :--- | :--- | :--- | :--- |
| **增额终身寿险（固收/分红）** | ¥5,000 ～ ¥5万 / 年起 | 趸交 / 3年 / 5年 / 10年交 | 趸交或 3–5 年交通常 **4～8 年回本**（仅看保证利益则更长） |
| **养老年金险（固收/分红）** | ¥1万 ～ ¥10万 / 年起 | 3年 / 5年 / 10年 / 20年交 | 锁定至 55/60 岁起按月/年领终身现金流，前期现金价值普遍较低 |
| **快返型年金 / 教育金** | ¥1万 / 年起 | 3年 / 5年交 | 第 5 年起开始返钱，但长期综合 IRR 通常低于纯养老年金 |

## 5. 核心考量因素优先级

| 权重 | 考量因素 | 筛选硬标准 | 为什么排这里 |
| :---: | :--- | :--- | :--- |
| **P0** | **资金闲置周期（流动性）** | 确认这笔钱至少 **8～10 年绝对用不到** | 前 3～5 年退保只能拿回极低现金价值，直接血亏本金，是储蓄险头号杀手 |
| **P0** | **保证 IRR vs 演示 IRR** | 用 Excel/AI 算清**纯保证利益复利 IRR**与**含分红演示 IRR** | 业务员口头喊的“单利 4%~5%”全是营销话术，唯一能横向对比的标尺是**内部收益率（复利 IRR）** |
| **P1** | **历史分红实现率与保司实力** | 查保司官网披露的**近 3–5 年历史分红实现率**、综合投资收益率与偿付能力 | 分红是不保证的！保底之外能不能真正拿到钱，完全取决于保司的投资实力与历史兑现口碑 |
| **P1** | **减保规则写进合同** | 看清**部分退保（减保）上限**（如每年最多减 20% 基本保额或已交保费）是否白纸黑字写进合同 | 没写进合同的“灵活领取”未来随时可能被保司收紧规则 |
| **P2** | **红利分配方式** | 分清**现金红利**（复利生息/直接领）与**增额红利**（滚入保额，长期复利更强但前期变现慢） | 决定你未来的现金流节奏和复利滚雪球效率 |
| **P2** | **税务与合规变化** | 关注资本利得/分红收益相关税务政策走向 | 储蓄险本质是投资工具，做长期测算时要预留一定税务与通胀安全边际 |
| **P3** | **附加万能账户 / 养老社区** | 别为了画大饼的养老社区门槛硬凑几十上百万保费 | 多数养老社区只是优先入住权（住进去照样交高额月费），且万能账户结算利率近年持续下行 |

## 6. 主要误区

1. **❌ “销售说‘年化收益 4.5%’，比银行定期高多了，闭眼冲！”**
   → **✅ 真实情况**：这是最常见的数字魔术——对方大概率把**单利**说成收益，或者把**完全不保证的高档演示分红**当成了确定收益！在当下预定利率下调大背景下，内地储蓄险写进合同的**保证复利 IRR**通常只有 **1.5%～2.0% 左右**，加上合理分红预期（按 70%～100% 实现率折算）才可能到 **2.5%～3.2%+**，务必自己算清复利 IRR。
2. **❌ “当成活期存钱罐，手头紧了随时把钱取出来应急”**
   → **✅ 真实情况**：大错特错！前几年现金价值远低于你交的保费（第一年退保可能亏掉 30%～50% 本金）。这绝对不是应急钱包，只能用**真·长期闲钱**买。
3. **❌ “基础医疗险和意外险还没买，先花 5 万买份分红储蓄险‘顺便带点保障’”**
   → **✅ 真实情况**：严重本末倒置！储蓄险的身故保障杠杆几乎为 1（只赔已交保费或现金价值略高一点），生大病根本救不了急。**先保障、后理财**是铁律。

## 7. 投保前 AI 核对重点

把候选产品的**《利益演示表（含保证利益与红利利益完整现金价值表）》+《合同条款 PDF》+《保司官网分红实现率公告》**喂给 AI，直接复制下面这段 Prompt：

```text
你是一位懂精算与现金流折现的客观理财顾问。我上传了候选分红储蓄险的【利益演示表、合同条款与分红实现率资料】，计划投入【每年交 X 万，共交 Y 年】。请帮我剥离营销话术、还原真实收益与风险，并遵守证据铁律：**所有数字与规则结论必须附上利益演示表对应年份/列数据及合同条款原文编号与摘录，IRR 必须写出计算逻辑，严禁使用“大概”“差不多”或单利混淆。**

请按以下 4 项输出核查表：
1. 【真实复利 IRR 测算】：分别计算第 10 年、第 20 年、第 30 年的 ① **纯保证利益复利 IRR**、② **演示分红 100% 实现时的复利 IRR**、③ **分红仅实现 50% 时的压力测试 IRR**。
2. 【回本周期与早期退保亏损】：明确标出“纯保证现金价值 ≥ 累计已交保费”是第几年；并列出第 1 年、第 3 年、第 5 年退保分别会亏损多少本金（绝对值与比例）。
3. 【减保与领取刚性条款】：摘录合同中关于“减保比例限制、减保频率、保单贷款利率”的原话，判断资金灵活性是否真正锁定在合同里。
4. 【分红底牌核验】：结合提供的分红实现率数据，指出该保司近 3 年同类分红产品的实际兑现趋势，并对比当前同期国债/稳健固收资产的利差，客观给出“值不值得锁定 10 年”的决策参考。
```
