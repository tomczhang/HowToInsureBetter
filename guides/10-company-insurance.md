## 1. 核心定位

> **公司福利是“加餐”，自己的底仓才“保命”——在职期间性价比拉满的公费大礼包与低价内部互助，但离职当天自动清零，绝不能用来替代个人长期商业险。**
>
> 许多互联网大厂、国企与外企除了给员工统一采购团体商业险（自带日常门急诊报销、高额住院医疗、甚至免健告保既往症以及几十倍月薪的身故/全残兜底），还会配套**几十元/年保全家的内部员工互助计划**（覆盖本人、配偶及未成年子女的重疾、身故与意外残疾）。正确用法是：**在职把公费和低价互助全薅满，同时把个人底仓握在自己手里，两者互补最划算。**

## 2. 配置优先级

`🟡 在职必用（公费直接用、低价内部互助闭眼参，但同步配齐个人 P1 底仓）` —— 公司公费送的部分在职期间一定要第一时间用起来（看病报销门急诊，还能帮个人百万医疗抵扣免赔额）；如果公司有几十元/年保全家的内部员工互助计划，几乎零现金流占用、杠杆拉满，建议每年必续别断缴；但千万别因为它省掉个人商业险，更不要把全家保障押在一张工牌上。

## 3. 适合谁

| 人群 | 推荐度 | 配置策略与关注重点 |
| :--- | :--- | :--- |
| **少儿** | 🟢 薅家属包+互助彩蛋 | 很多公司支持花几百块给娃挂载团险补充医疗（日常感冒发烧门急诊报销极香）；若公司有**低价员工互助计划**，务必在娃出生前起持续参与——部分大厂互助计划连商业险一律免责的**先天性心脏病开胸手术**都能援助（常要求出生时与确诊时父母均参保）。同时务必给娃配个人 20 年保证续保百万医疗 |
| **家庭支柱** | 🟢 在职必用+补底仓 | 本人直接享受公费福利，叠加几十元/年的内部互助计划后，在职重疾与身故杠杆直接翻倍（配偶通常也能同步沾光）；但必须趁体检干净买断个人**20 年保证续保百万医疗 + 综合意外险**，防止“生病 + 离职”双杀 |
| **退休长辈** | 🟢 父母非标体神器 | 若公司开放父母自费团险且**免健告或保既往症**，对买不了个人百万医疗的高龄/三高父母是极香外挂；同时务必配好**地方惠民保**防员工离职断档 |

## 4. 大概成本

*企业内部保障通常由“公司公费基础包 + 员工内部互助计划 + 员工/家属自费升级包”三层构成，不同企业福利档次差异极大（以下以一线互联网大厂/外企常见方案为例）。*

| 参保模块 | 适用对象 | 年缴参考成本 | 保障与成本特征 |
| :--- | :--- | :--- | :--- |
| **员工公费基础包** | 员工本人 | ¥0（公司全额买单） | 常见含 1万～2万门急诊/住院补充医疗 + 高额住院医疗（部分保既往症）+ 10万左右重疾 + 24～36 倍月薪身故/全残 |
| **员工内部互助计划** | 本人 + 配偶 + 18 岁以下未婚子女 | ¥50 ～ ¥100 / 年（全家） | **性价比极高的在职外挂**（如 80 元/年保全家）：本人常含 15 万重疾（5 年内自费超 5 万可再补 5 万）+ 3 万轻症 + 20 万身故/伤残；配偶及子女各含 10 万重疾/身故/伤残 + 3 万轻症；部分还破例覆盖符合条件的**先天性心脏病开胸手术** |
| **员工自费升级包** | 员工本人 | ¥200 ～ ¥1,500 / 年 | 可升级特需部、齿科或加高保额；性价比通常优于散买，但同样**离职即失效** |
| **配偶 / 子女家属包** | 配偶、少儿 | ¥300 ～ ¥1,200 / 人·年 | 核保极宽、日常门急诊报销香；尤其适合 0–5 岁高频看病期婴幼儿当“小额医疗外挂” |
| **父母自费团险包** | 双方父母 | ¥800 ～ ¥3,000 / 人·年 | 许多企业版对父母**免健告或宽松核保**，非标体老人性价比极高，但需留意既往症赔付细则 |

## 5. 核心考量因素优先级

| 权重 | 考量因素 | 核查硬标准 | 为什么排这里 |
| :---: | :--- | :--- | :--- |
| **P0** | **离职失效与零保证续保** | 明确离职当日（或当月末）团险与互助是否同步终止、有无转个人险通道 | 团险和内部互助最大死穴是跟工牌绑定、离职当天立即失效；**哪怕离职当天立刻自购个人险，也会面临等待期空窗，且届时体况能不能买到也不好说** |
| **P0** | **既往症与等待期约定** | 区分“大额医疗 / 补充医疗 / 重疾 / 互助”各自是否保既往症、有无等待期 | 常见情况是**团险大额医疗保既往症、公费重疾 0 等待期，但团险重疾与互助均不保既往症**，不看清条款极易误判 |
| **P1** | **报销缝隙与自费耗材盲区** | 核查丙类自费药、丙类诊疗项目及高值耗材的报销比例与起付线 | 很多公司日常补充医疗不报丙类诊疗，而大额医疗免赔额又在 1万～2万，0～2 万区间存在隐形盲区 |
| **P1** | **重疾与身故保额缺口** | 对比公费重疾（常仅 10 万）+ 内部互助叠加额，以及身故倍数（常 24～36 倍月薪） | 单靠公费重疾杯水车薪，叠加内部互助后在职虽能垫厚到 25万～30万，但离职即归零；身故高倍数在职很香，背房贷怕跳槽仍需锁个人定寿 |
| **P1** | **内部互助的门槛与合同性质** | 核查配偶婚后确诊限制、子女出生时连续参保要求、病种国标边界（如原位癌不赔） | 员工互助本质是企业内部公益互助而非受《保险法》刚性约束的长期合同，规则可能随当期调整，且对结婚日/出生日和连续参与有硬门槛 |
| **P2** | **与个人商保的抵扣衔接** | 核实住院时先报公司团险，剩余自付能否抵扣个人百万医疗 1 万免赔额 | 用对顺序可以实现“公司团险报掉前 1 万，个人百万医疗 0 自付起赔”的黄金组合 |
| **P2** | **家属自费包性价比与核保** | 对比自费挂载价与市面个人险，重点看是否免健告、含不含门急诊 | 给娃看重日常门诊报销，给父母看重宽松核保/保既往症；健康成年配偶通常不如直接买个人长期险稳妥 |

## 6. 主要误区

1. **❌ “公司给我买了 600 万团险，连既往症都保，我自己根本不用买百万医疗险”**
   → **✅ 真实情况**：最危险的错觉！公司团险**离职当天立即失效、零保证续保**；哪怕离职当天立刻自己买，也会遇到等待期问题，而且那时候体况能不能买到也不好说。花几百块提前配好个人 20 年保证续保百万医疗，这份钱绝不能省。
2. **❌ “公司团险带了重疾和补充医疗，大小病全包圆，省心！”**
   → **✅ 真实情况**：拆开合同往往吓一跳——公费团险重疾保额常只有 **10 万左右**（且多数不保既往症、病种少），真生大病连半年开销都不够；日常补充医疗也常漏掉**丙类诊疗/进口耗材**，0～2 万区间依然要自己掏腰包（顺手补份不限社保的个人意外险能堵掉一大半意外耗材缝隙）。
3. **❌ “公司有 80 元员工互助计划，全家都有重疾和身故，能替代个人重疾险和定寿”**
   → **✅ 真实情况**：几十元保全家的内部互助杠杆逆天，**在职闭眼必参、尽量不断缴**（部分还破例保符合条件的子女先天性心脏病），但它依然有两条底线：① 属于**企业内部互助**而非受《保险法》约束的商业合同，**离职即退出**且规则随年度微调；② 病种多按 2020 重疾新规执行（原位癌不赔、Ⅰ期甲状腺癌仅按轻症赔），配偶通常限婚后首次确诊。把它当成在职期间的白菜价叠加外挂，个人底仓依然不能省。
4. **❌ “只要我稳住不跳槽，公司团险就能保我到退休”**
   → **✅ 真实情况**：团险和互助计划都是公司每年重新评估招标的，遇到行业周期下行降本增效，次年福利缩水、提高免赔额甚至取消家属包都很常见；**只保在职的福利不是铁饭碗，别把人生底线赌在工牌上**。

## 7. 投保前 AI 核对重点

入职、每年公司开放团险续保/升级或内部互助计划窗口，或者打算给家人买自费团险包时，把内网下载的**《企业团体商业保险保障方案 / 合同条款 / 理赔手册 / 员工互助计划规则与病种附件 PDF》**连同你现有的个人保单清单一起喂给 AI，直接复制下面这段 Prompt：

```text
你是一位站在员工个人与家庭风控立场的保险条款分析顾问。我上传了公司内部发放的【企业团体商业保险方案/合同条款/理赔手册/员工互助计划规则与病种附件】，我目前【年龄、家庭负债与成员情况、已买的个人商业险清单】。请帮我彻底拆解这份公司保障的真实含金量与隐藏硬伤，并遵守证据铁律：**每一条结论必须附上文件里的对应章节/页码及关键原话摘录，文件里未写明的直接标注“方案原文未明确说明”，严禁凭经验臆测。**

请按以下 5 项输出核查结果：
1. 【公费福利亮点清单】：拆解员工本人享有的门急诊报销比例、住院报销比例、是否覆盖丙类自费药/院外特药、大额医疗是否保既往症、以及意外/疾病身故与猝死的具体保额倍数。
2. 【致命硬伤与报销缝隙排查】：明确标出 ① 离职后保障具体何时终止、有无转个人保单权益；② 公费重疾保额、病种数量、等待期及是否剔除既往症；③ 补充医疗与大额医疗之间是否存在“丙类诊疗/自费耗材/免赔额断层”盲区。
3. 【员工内部互助计划核查】：若公司提供几十元/年类的员工互助计划，拆解本人/配偶/子女各自的援助额度、重疾大额自费二次援助条件、病种清单是否对齐 2020 国标（原位癌、Ⅰ期甲状腺癌及先天性疾病如何界定），以及配偶结婚日、子女出生日与连续参保的硬门槛。
4. 【与个人底仓的精准补齐清单】：结合我已买的个人险，告诉我哪几项在职期间可以放心用公司团险+互助顶着（不花冤枉钱），哪几项必须立刻自费补齐个人底仓，并说明生病住院时“医保 → 公司团险 → 个人百万医疗”的最佳报销衔接顺序。
5. 【家属自费包值不值得买】：若方案包含配偶/子女/父母自费加购选项，逐一拆解其价格、健康告知要求、既往症赔付规则及免赔额，给出“建议买 / 不建议买”的明确理由。
```
